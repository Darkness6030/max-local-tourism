# Пресеты поездок

Все каталоги лежат в `src/assets/`:

- `cities.json` — города отправления, их оформление и региональные настройки. [Подробности](CITIES.md).
- `mood-presets.json` — карточки «Как хочется отдохнуть?», которые заполняют интересы и темп в анкете.
- `trip-presets.json` — готовые редакционные маршруты по городам с программой, расходами, списком вещей и источниками.

Секретов и персональных данных в этих файлах быть не должно. Пресеты входят в публичную сборку интерфейса. Изменение пресетов требует пересборки фронтенда; стандартный деплой через Git делает её автоматически.

## Добавить карточку по настроению

Добавьте объект в массив `mood-presets.json`. Порядок записей определяет порядок карточек. Пример (не добавлен в рабочий каталог):

```json
{
  "id": "museum-day",
  "title": "День в музеях",
  "subtitle": "Искусство и история",
  "illustration": "city",
  "interests": ["Музеи", "История"],
  "pace": "balanced",
  "color": "#faede3",
  "ink": "#ae8572"
}
```

`id` должен быть уникальным: строчные латинские буквы, цифры и дефисы. `pace`: `relaxed`, `balanced` или `intensive`. Готовые иллюстрации: `nature`, `city`, `coffee`, `route`. Цвета задаются как `#RRGGBB`. Интересы берите из вариантов анкеты. Новая карточка с одной из готовых иллюстраций не требует изменений React.

## Добавить маршрут по городу

Скопируйте объект из `trip-presets.json` и заполните:

- `id`, `city`, `origin`, `title`, `tagline`, `summary` — идентификатор, направление, город отправления и тексты.
- `photo` — имя файла в `frontend/src/assets/presets/`, например `kolomna.jpg`. Поддерживаются JPG, JPEG, PNG и WebP. Фотография автоматически попадает в сборку, отдельный импорт не нужен. Заполните `photoAlt`, `photoAuthor`, `photoSource` и соблюдайте лицензию изображения.
- `interests`, `pace`, `maxTravelMinutes` — параметры для заполнения анкеты.
- `budgetRub`, `budgetItems` — ориентир расходов и его состав. Сумма `amount` должна совпадать с `budgetRub`. Отрицательные расходы недопустимы.
- `travel`, `tip`, `packing`, `sources` — транспортная справка, совет, вещи и проверяемые ссылки на места.
- `days` — от одного до трёх дней. У каждого есть `title` и непустой `stops`, у остановки — `time`, `title`, `place`, `description`.

Маршрут показывается только для своего `origin`; город должен присутствовать в `cities.json`. Для отключённого города карточки не отображаются. При удалении города из каталога удалите или перенастройте связанные пресеты.

Время в редакционной программе — предложение по распределению дня, а не подтверждение сеанса или часов работы. Не включайте выдуманные рейсы, прогноз и цены. Кнопка «Хочу так же» переносит параметры в анкету: даты, прогноз и расписание пользователь получает в обычном сценарии планирования.

## Проверка и публикация

```bash
npm --prefix frontend run build
.venv/bin/python -m src.cities
```

Сборка проверяет структуру и типы полей, уникальность ID, темп, иллюстрации, наличие фотографий, длительность маршрутов, города отправления и сумму расходов. Пустые массивы пресетов допустимы. Для проверки взаимодействий используйте `scripts/check_presets.py` и `scripts/check_profile_ui.py` из README. После проверки закоммитьте изменения, отправьте их в `origin/main` и запустите `python3 scripts/deploy.py`.
